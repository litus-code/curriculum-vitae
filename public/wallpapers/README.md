# Approved Carles Far OS wallpapers

Place the two approved 1536×1024 WebP files here:

- `sunset.webp`, pixel-art sunset with striped yellow-lime sun
- `night.webp`, same mountain-scape at night with the full moon

The homepage loads these using `useRuntimeConfig().app.baseURL` so GitHub Pages subpaths work. Until both files exist, the client falls back to the procedural CSS art. Do not substitute generated placeholders for the user's approved images.
