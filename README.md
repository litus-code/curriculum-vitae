# Carles Far OS
Personal portfolio rebuild in Nuxt 4, Vue 3 and TypeScript.

## Development
Node 24.15+, npm 11. Run `npm install`, then `npm run dev`. Run `npm run check` to typecheck, test and generate static output.

## Workflow
See `AGENTS.md`, `docs/AGENT_WORKFLOW.md`, `docs/ARCHITECTURE.md` and `docs/HANDOFF.md`.

This is an **unreleased draft**. The previous live carlesfar.com remains unchanged. Selected services are copied to a mailto demo. No server receives submissions.

## Acceptance targets
Vintage pixel desktop visually matching the approved design, selected service checkboxes, CAT/ES/EN, light/dark mode, controlled optional audio, interactive terminal, accessible keyboard/mobile operation and project details. See docs/HANDOFF.md for unverified items.
